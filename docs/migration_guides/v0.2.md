# Migration Guide for v0.2

Migrating from `0.1` (`v0.1`) to the latest `0.2.x` (`v0.2`).

## Required changes

- **`BaseEventHandler` no longer resolves string method names on `handler_class`**: pass a `handlers` dict of callables into `__init__`. `handler_class` is gone.

### Migration steps

1. Stop setting `handler_class` and string handler names. Pass callables:

   ```python
   # Before (0.1)
   class MyHandler(BaseEventHandler):
       handler_class = SomeClass
       handlers = {"FooHappened": "on_foo"}

   # After (0.2)
   handler = BaseEventHandler(handlers={"FooHappened": some_callable})
   ```
