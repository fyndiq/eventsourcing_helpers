# Migration Guide for v0.8

Migrating from `0.7` (`v0.7.9`) to the latest `0.8.x` (`v0.8.13`).

## Required changes

- **`ESEntityBuilder` removed** (`0.8.3`): use `eventsourcing_helpers.repository.builder.AggregateBuilder` (aggregate class is passed to `__init__`, not `rebuild`).
- **`cnamedtuple` is an extra** (`0.8.6`): it is no longer installed by default. `pip install eventsourcing-helpers[cnamedtuple]` if you still need it; otherwise stdlib `namedtuple` is used.
- **DTO metadata attribute** (`0.8.7`): serializers set `Meta` on the DTO, not `meta`.
- **`Message.to_dict()` keeps `None` values** (`0.8.6`): it no longer drops null fields.

### Migration steps

1. Replace the entity builder:

   ```python
   # Before (0.7)
   from eventsourcing_helpers.builders import ESEntityBuilder
   builder = ESEntityBuilder(repository_config=config)
   order = builder.rebuild(entity_class=Order, id=order_id)

   # After (0.8)
   from eventsourcing_helpers.repository.builder import AggregateBuilder
   builder = AggregateBuilder(config, aggregate_root_cls=Order)
   order = builder.rebuild(id=order_id)
   ```

2. If you imported `cnamedtuple` via this package, install the extra (or switch to `collections.namedtuple`).
3. Read `dto.Meta` instead of `dto.meta`. If you relied on `to_dict()` omitting `None`, filter those keys yourself.

## Optional changes

- **Mock message bus** (`0.8.6`): backend alias `mock` for tests (`add_message(message_class=..., data=...)`).
- **`Snapshot.delete`** (`0.8.0`): snapshots are deleted on command-handler errors; call `delete` yourself only if you manage snapshots directly.
- **Produce/consume headers** (`0.8.7`): mock assertions can include headers; serializer field is `Meta`.
- **`confluent-kafka-helpers` unpinned then `>=0.7.6`** (`0.8.10`–`0.8.13`): upgrade the helper independently within that range.
